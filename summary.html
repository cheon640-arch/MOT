The Big Map 전체 흐름 지도

중간고사 범위는 강의의 첫 번째 큰 질문 — “혁신은 어디에서 비롯되고, 기업은 왜·무엇을 위해 혁신하며, 어떻게 이익을 확보하는가?” — 에 대한 답이에요.

01 · Introduction to MOT

“혁신은 결과물이자 과정, 필요와 해결책의 결합”

  • 혁신 = 창조적 파괴 (Schumpeter 1942) — 기존 기업의 존립 자체를 위협하는 경쟁
  • Mark I (1911): 기업가·신생기업, 진입 자유·소규모 → entrepreneurial (초기 카카오) / Mark II (1942): 대기업·독점, 사내 R&D → routinized (삼성 반도체)
  • Baumol: 성장은 혁신이 주도, 혁신은 생존전략 · Solow: \(Y = AK^\alpha L^{1-\alpha}\)
  • 정의: Hauschildt (질적으로 새로운), Porter (상업화된 새로운 방식), Afuah (새 아이디어의 채택)
  • 유형: 제품/서비스 (시장) · 프로세스 (조직 내) · 비즈니스 모델 (이케아)

꼭 외울 것

  • Prozac (13년, 특허 만료) vs Iridium (기술 성공, 사업 실패)
  • 더 나은 쥐덫의 오류 — Low-Tech 가 이길 수 있음
  • Pearson 2×2: 마케팅 중심 · 시장/기술 동시 · 점진적 · R&D 기술중심
  • R&D: 기초 5–20 / 응용 15–25 / 개발 65–85%

헷갈리는 점

  • R&D 는 필수지만 충분 원동력은 아님, 해결책 관련 지식만 생산
  • PARC = 주인-대리인, 바사호 = 조직(거버넌스)

02 · Patterns in Innovative Activity

“혁신은 패턴을 따른다 — 사후적으로만 보일지라도”

  • 기술 변화는 누적적·진화적, 일부는 혁명적 → 기술경제적 패러다임
  • GPT 조건: 확산 · 후속 개선 · 다른 혁신을 가능하게 (증기기관)
  • 콘드라티예프 40–60년, 점점 짧아짐, 6th wave AI
  • S-곡선 4단계, 범선 효과, 이슈(입력 변수·형태), 성배는 아님
  • 지배적 디자인 → 퇴출/생존 + 제품→공정 혁신 전환 (모델 T, 폐쇄형 스틸 차체)
  • PLC: 유동기 → 전환기 → 고착기
  • 로저스 5분류, 캐즘(Moore), 배스 확산 모형

꼭 외울 것

  • PLC 경쟁: 성능 → 다양성 → 가격 / entries >, =, < exits
  • 2.5 / 13.5 / 34 / 34 / 16
  • p = 혁신계수 (독립), q = 모방계수 (네트워크)
  • 로지스틱 최대 판매 = \(N_{total}/2\)

헷갈리는 점

  • p, q 는 가격·수량이 아닌 상수
  • 오피니언 리더 = 초기 수용자 (혁신 수용자 아님)
  • 캐즘 = 초기 수용자 ↔ 초기 다수

03 · Sources and Patterns of Innovation

“어떤 혁신인지 알아야 대응하고, 어디서 오는지 알아야 만든다”

  • 4쌍: 제품/공정 · 급진적/점진적 (상대적: 시간·관찰자) · 역량강화/소실 (기업 관점) · 구조적/부품
  • Anderson & Tushman: 기술 사이클 (유동기 → 지배적 디자인 → 고착기), 지배적 디자인은 최첨단 아님, 기능 번들
  • 원천: 창의성(개인·조직) → ① 혁신가 ② 소비자 ③ 기업 R&D ④ 외부 연계 ⑤ 협력 네트워크
  • Science Push (선형) vs Demand Pull (고객 요구)
  • 흡수능력, Bayh-Dole Act (1980), 클러스터·집적경제, 기술 파급

꼭 외울 것

  • 카카오뱅크 급진 / 현대차 페이스리프트 점진
  • 삼성 D램→낸드 강화 / 두산 소비재→중공업 소실
  • Z 폴드 구조적 / 48V 마일드 하이브리드 부품
  • 파급 3요소: 보호 강도 · 지식기반 · 인력 이동성

헷갈리는 점

  • 구조적 혁신은 부품 자체 변화도 동시에
  • 발명가는 많이 발명해도 상용화는 드물다

04 · Who innovates, and why?

“가장 큰 이익을 얻는(비용이 가장 낮은) 주체가 혁신한다”

  • 애로우: A 완전경쟁→독점 (이득 □ABCD), B 독점→독점 (□ABCD − □EFGH, 자기잠식), C 사회계획자 (□AIJE)
  • 매몰비용 F 감수 순서: B < A < C
  • 효율성 효과 (약간 나은 혁신, 독점 유지) vs 자기잠식 효과 (급진적, 기존 기업 손해)
  • 실증: 획기적 혁신은 신규 진입자에서
  • 정책: 사회적 이익 > 사적 이익 → 시장실패 → F 만 낮춰 주기 (한국 반도체 ↔ 일본 5세대)
  • DMA: 게이트키퍼 규제 = Mark II 제한
  • 신생기업 부담(newness) vs 작은 기업 부담(smallness), SAP
  • 파괴적 혁신 (Christensen): 단순 → 틈새 → 성능이 수요보다 빠르게 → 주류 대체

꼭 외울 것

  • \(MR = a - 2bq = MC\)
  • InnovaPNU 156.25 → 2025, 1868.75, c′ ≤ 50, F ≤ 625
  • Seagate 3.5인치 = 고객에게 발목

헷갈리는 점

  • 우버는 파괴적 혁신 아님 (틈새 X, 처음부터 월등)
  • 파괴적 ≠ 급진적 (시장적 이유)
  • Arrow 급진적 = 독점가격조차 c₀ 보다 낮음

05 · Innovation Strategy

“Strategy is about making choices!”

  • 전략 = 장기 목표 + 단계·자원 배분, 장기적 경쟁우위, 변경 비용 큼
  • RBV(내부: 강점·약점) + MBV(외부: Five Forces, 기회·위협) 통합, 기업전략 → 혁신전략
  • VRIN + 모방 어려운 조건 (암묵·경로의존·사회적 복잡·인과 모호·IPR·고유)
  • 혁신을 위한 자원 6: 재정·인적·기술·마케팅·조직·네트워킹
  • 5요소: 목표 · 중점 분야 · 유형 & 위험 · 예산 & 자원 · R&D 조직
  • Push vs Pull vs Combination, IBM 전략 변화

꼭 외울 것

  • Big bets · Hedging · Wait and see (Intel = big bets)
  • 70-20-10
  • 선제 DuPont·Apple / 활동 MS·Dell / 대응 Ryanair / 수동 Ratiopharm
  • Honda 핵심역량 = 엔진·파워트레인

06 · Value in Platforms

“기술이 좋아서가 아니라, 많이 쓰여서 표준이 된다”

  • 수익체증 = 학습효과 + 네트워크 외부성 (직접: 철도·통신 / 간접: Windows)
  • 사전학습 · 흡수능력 → 먼저 채택된 기술이 유리
  • 자기강화 사이클 (고객기반 ↔ 보완재), MS-DOS, 경로의존성
  • 정부 규제 (USB-C, 두벌식), 승자독식 (가솔린차)
  • 가치 = 독립적 가치 (기능·심미·사용 용이성) + 네트워크 외부성 가치 (고객기반·보완재)
  • 실제 · 인식 · 기대 (NACS, 초기 GPT), 경우 1·2·3, 무차별 지역
  • 모듈화 3단계, 플랫폼 생태계 vs 경계, 통합 ↔ 플랫폼 ↔ 모듈화

꼭 외울 것

  • 구매자 효용 지도 6 × 6 = 36칸
  • NeXT vs Windows
  • Odyssey → Wii U → Android
  • MS 반독점: 분할 대신 API 공개·호환성

헷갈리는 점

  • 보완재 가용성은 독립적 가치가 아님
  • 생태계 = 플랫폼 안에서 선택 / 경계 = 플랫폼 자체를 선택

07 · Profiting from Innovation

“혁신가가 아니라 독보적인 입지에 있는 누군가가 이익을 얻는다”

  • 이익 분배: 혁신가 · 고객 (평가 > 가격) · 공급·보완업체 (판매량) · 모방업체 (R&D 절감)
  • 고객: 소비자 잉여, 사중손실
  • 이중마진화: 분리하면 수량·총이윤 감소, 병목 자원 통제자가 더 번다
  • Teece 3요소: 수명주기 단계 · 전유성 체제 · 보완적 자산
  • 전유성 요인: 전통적 (법적 보호, 비밀유지, 기반기술) + 성격이 다른 (네트워크, 전환비용, 규모, 진입 용이성)
  • 패러다임 이전: 지배적 디자인 확립 능력 / 이후: 보완적 자산 통제
  • 범용 · 특화 · 상호특화, 계약 vs 통합, 홀드업
  • 제품시장(경쟁) vs 아이디어시장(라이선스·매각·제휴), 공개의 역설

꼭 외울 것

  • 1/2, 1/4, 1/8, 1/16, 3/16 vs 1/4, 3/4
  • Teece 2×2 매트릭스 네 칸
  • Strong 특허 = 제약 / 비밀 = 음료·타이어 / Weak = SW·의류
  • Comet 1, TYRX → Medtronic

헷갈리는 점

  • 전기 = 범용 자산, 트럭 = 특화, Stryker·iOS = 상호특화
  • 네트워크 효과로 특허 없이도 전유성 가능

08 · IP Protection

“특허는 출원일부터 20년, 그리고 나라마다 따로”

  • 공식: 특허 · 등록디자인 · 상표 · 저작권 · 비밀유지계약 / 비공식: 비밀유지 · 리드타임 · 설계 복잡성 · 전환비용 · 네트워크 외부효과
  • 기능·구조·방법 → 특허, 이름 → 상표, 외관 → 디자인
  • 특허 요건: 신규성 · 진보성 · 산업상 이용 가능성 / 불가: 과학적 발견, 수학, 심미, 영구기관, 공공질서
  • 국가별 차이: SW (한국 HW 결합, 유럽 기술적 효과, 미국 추상적 아이디어), BM, 식물특허
  • 디자인: 신규성 · 창작비용이성 · 공업상 이용 가능성
  • 저작권: 표현 보호, 자동 발생, 사후 70년, 오픈소스
  • 특허와 VRIN (✅ / ❌ 장롱특허·표준화·공개성·우회기술), 혜택 vs 비용
  • 속지주의 · 파리협약 · PCT · EPO/USPTO/KIPO · CRISPR

꼭 외울 것

  • 18개월 공개 · 16개월 등록 · 12개월 우선권 · 30개월 PCT
  • 디자인 20년 연장 불가 · 실용신안 10년
  • CRISPR: 선발명 → 선출원 (미국 2013)

헷갈리는 점

  • 비밀유지계약 = 공식, 비밀유지 = 비공식
  • PCT 출원 ≠ 국제특허 등록
  • 등록일이 아니라 출원일 기준
